# DM-32UV FW パッチャ(日本語メニュー版)

Baofeng DM-32UV の **L01.048** 用のパッチツールです。ブラウザで動きます。

**ツール: https://ja2izu.github.io/DM32UV-JaPatcher/**

元のファームウェアはここには含まれていません。公式サイトから入手したファイルに、差分を適用して使います。ファイルは、ブラウザの中だけで処理され、外部には送信されません。

## できること

- 周波数ステップ: 20kHz の追加と並べ替え(5 / 6.25 / 10 / 12.5 / 20 / 25 / 50 / 100 kHz)
- エアバンドのステップを 25kHz に
- 日本語メニュー(中国語表示を日本語に置き換え。英語側は変更しません)

3つは、個別に選べます。

日本語メニューの表示には、フォントの書込みが必要です。 → [DM32UV-ModJaFont](https://github.com/ja2izu/DM32UV-ModJaFont)

## 使い方

1. 元のファームウェアを入手します(下記)。
2. ツールのページで、そのファイルを選びます。元のファイルかどうかが、自動で照合されます。
3. 適用する内容を選んで、ボタンを押します。
4. 作成された .bin を、いつもの手順で無線機に書き込みます。

## 元のファームウェアの入手

1. [Baofeng 公式のダウンロードページ](https://baofengradio.com/pages/download)を開きます。
2. 一覧から「DM Series」の DM-32UV を選びます。
3. 「Firmware V1.01.048 [15W Contacts + No Record]」をダウンロードします。
4. zip を展開し、中の `DM32_L01_048_20250821.bin` を使います。

照合に使う値です。

| サイズ | 860,416 バイト |
